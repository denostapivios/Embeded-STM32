# # Мініпроект. Читання даних з Терморезистора (STM32)
Реалізовано вимірювання температури за допомогою термістора NTC 10K B3950 на мікроконтролері STM32.
- Tермістор підключено у вигляді подільника напруги, а сигнал зчитується через 12-бітний ADC.
- На основі RAW-значення АЦП обчислюється напруга, опір NTC та температура за Beta-формулою.
- Результати вимірювань виводяться через USB CDC у термінал.
  
**Налаштовано:**
  - DC1_IN1 на піні PA1;
  - 12-бітний АЦП із діапазоном значень 0–4095;
  - USB Device у режимі CDC;
