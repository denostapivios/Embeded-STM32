# STM32 PWM Control — LED & DC Motor
Проєкт на STM32, у якому реалізовано керування яскравістю світлодіода та швидкістю DC-мотора за допомогою PWM.

Що реалізовано:
- Потенціометр зчитується через ADC1.
- Значення ADC перетворюється у PWM Duty Cycle.
- Кнопка перемикає два режими роботи:
    - LED Mode — потенціометр керує яскравістю LED.
    - Motor Mode — потенціометр керує швидкістю DC-мотора.
- LED та мотор працюють незалежно один від одного.
- Мотор керується через NPN-транзистор ST2N2222A.
- Для захисту транзистора використовується flyback diode 1N400x.
- Логи передаються через USB CDC.
