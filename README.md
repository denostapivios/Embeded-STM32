# RTC DS1307 — I2C — STM32
Проєкт реалізує роботу з модулем годинника реального часу (RTC) DS1307 на мікроконтролері STM32F401CCU6. Обмін даними між мікроконтролером і RTC-модулем здійснюється через інтерфейс I2C.

## Реалізовано

- Ініціалізація I2C та перевірка доступності DS1307.

- Зчитування секунд, хвилин, годин, дня тижня, дати, місяця та року.

- Перетворення даних між форматами BCD і Decimal.

- Перевірка прапорця зупинки годинника (Clock Halt, CH).

- Запуск генератора DS1307 та встановлення початкового часу, якщо годинник зупинений.

- Виведення поточної дати й часу через USB CDC.

- Періодичне оновлення логів з інтервалом 1 секунда.

- Обробка помилок під час підключення та зчитування даних із RTC-модуля.

- Розділення логіки на окремі функції для ініціалізації, роботи з RTC та виведення логів.

## Апаратне забезпечення

- Мікроконтролер: STM32F401CCU6

- RTC-модуль: DS1307

- Інтерфейс зв'язку: I2C

- Виведення логів: USB CDC
