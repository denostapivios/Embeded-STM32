# STM32 Неблокуючий аудіоплеєр (Buzzer)
Реалізував неблокуючий аудіоплеєр для STM32F401CCU6 на базі STM32 HAL.

Що зроблено:
- Генерація звуку через TIM3 PWM
- Buzzer підключений до PA6 (TIM3_CH1)
- Реалізовано відтворення мелодії через масив нот Note
- Частота PWM змінюється відповідно до поточної ноти
- Реалізований апаратний TIM2 timer з періодом 50 мс
- Використано TIM2 interrupt для формування фіксованого time tick
- ISR лише встановлює volatile прапорець tick_50ms
- Перемикання нот виконується в основному циклі
- Реалізована неблокуюча логіка без HAL_Delay()
- Підтримуються паузи між нотами
- PWM duty cycle встановлений приблизно на 25% для зменшення різкості звучання
