# STM32 Traffic Light Refactoring
Перероблено структуру проєкту світлофора на STM32 з app.c / app.h

## Що змінено

- створено окремі файли `app.c` та `app.h`;
- основну логіку винесено з `main.c`;
- у `app.c` реалізовано функції `setup()` та `loop()`;
- `main.c` залишено для ініціалізації мікроконтролера та запуску основної логіки.

## Структура

```text
Core/
├── Inc/
│   ├── main.h
│   └── app.h
│
└── Src/
    ├── main.c
    └── app.c
