# STM32 ADC + DMA + UART — Зчитування аналогового сигналу

## Завдання
Реалізовано зчитування аналогового сигналу за допомогою ADC на мікроконтролері STM32 із використанням DMA для автоматичного перенесення даних у буфер. Для зменшення коливань вимірювань обчислюється середнє значення чотирьох вибірок. Результати перетворюються в напругу та передаються через UART за допомогою DMA.

## Що реалізовано
- Налаштування ADC для зчитування аналогового сигналу.
- Використання DMA у режимі Circular для автоматичного заповнення буфера.
- Зчитування чотирьох вимірювань ADC.
- Обчислення середнього значення для стабілізації результатів.
- Перетворення цифрового значення ADC у напругу в мілівольтах.
- Передавання результатів через UART із використанням DMA.
- Періодичне виведення даних кожні 500 мс.
- Розділення логіки програми на app.c та app.h із використанням функцій setup() і loop()

## Апаратне забезпечення
- Мікроконтролер: STM32F401CCU6
- Середовище розробки: STM32CubeIDE
- Конфігурація периферії: STM32CubeMX
- Бібліотека: STM32 HAL
