# STM32 BME280 Sensor 
Проєкт для зчитування температури, атмосферного тиску та відносної вологості за допомогою датчика BME280 і мікроконтролера STM32F401CCU6.

Проєкт використовує STM32 HAL для роботи з інтерфейсом SPI та офіційну бібліотеку Bosch BME280 SensorAPI для ініціалізації датчика, читання даних і компенсації вимірювань. Результати передаються на комп'ютер через USB CDC.

## Реалізовано

- Інтеграція офіційної бібліотеки Bosch BME280 SensorAPI.

- Обмін даними з BME280 через SPI1.

- Зчитування температури, атмосферного тиску та відносної вологості.

- Компенсація вимірювань за заводськими калібрувальними коефіцієнтами датчика.

- Передавання даних через USB CDC.

- Перевірка ідентифікатора датчика перед зчитуванням вимірювань.

- Виявлення послідовних помилок читання.

- Автоматичні повторні спроби ініціалізації після втрати зв'язку з датчиком.

- Модульна архітектура з окремим адаптером між Bosch API та STM32 HAL.


## Апаратне забезпечення

- Мікроконтролер: STM32F401CCU6

- Сенсор: BME280

- Інтерфейс зв'язку: SPI

- Виведення логів: USB CDC
