# Два світлодіоди та дві зовнішні кнопки
Реалізувати два режими миготіння світлодіодів в залежності від кнопки яка натиснута

- Під’єднав два світлодіоди та зовнішні кнопки до GPIO.
- Світлодіоди підключені до PAO та PA1.
- Кнопки підключені до РВО та РВ1.
- Реалізував два режими миготіння світлодіодів:
   1. Режим, що активується першою зовнішньою кнопкою
   2. Режим, що активується другою зовнішньою кнопкою
- При натисканні першої зовнішньої кнопки перемикав LEDs у швидший режим миготіння.
- При натисканні другої зовнішньої кнопки перемикав LEDs у повільніший режим миготіння.
- Миготіння та брязкіт контактів кнопок реалізував через delay(), **така була умова завдання**.
