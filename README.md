# Дослідження брязкоту контактів кнопки за допомогою логічного аналізатора та мікроконтролера (STM32)
- Рахую всі переходи сигналу LOW → HIGH на піні PA1 і виводжу загальну кількість зафіксованих імпульсів через USB Virtual COM Port
- Логічним аналізатором записав форму сигналу кожного натискання
- Для кожного натискання визначив кількість, скільки імпульсів брязкоту виникло насправді та їх тривалість

У STM32CubeMX пін PA1 було налаштовано як зовнішнє переривання:
