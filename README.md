# STM32 BME280 Sensor через CLI команди

## Опис проєкту
Реалізовано командний інтерфейс CLI для керування датчиком BME280 через USB CDC (Virtual COM Port). Користувач може вводити команди в терміналі для зчитування показників і перегляду останніх збережених значень.

## Реалізовані команди

| Команда | Функціонал |
|---|---|
| `help` | Виведення списку доступних команд. |
| `read` | Зчитування температури, атмосферного тиску та вологості зі збереженням результатів у пам'яті. Після успішного зчитування виводиться підтвердження. |
| `temp` | Виведення останнього збереженого значення температури в °C. |
| `pressure` | Виведення останнього збереженого значення тиску в hPa та mmHg. |
| `humidity` | Виведення останнього збереженого значення відносної вологості у %RH. |


## Реалізований функціонал
- Налаштування SPI для обміну даними між STM32 та BME280.
- Ініціалізація датчика та перевірка його доступності.
- Зчитування температури, атмосферного тиску та відносної вологості.
- Передавання команд і повідомлень через USB CDC.
- Реалізація CLI для керування датчиком через термінал.
- Збереження останніх зчитаних показників у пам'яті програми.
- Обробка помилок під час зчитування даних.
- Повторна спроба ініціалізації датчика в разі помилок.
- Відображення атмосферного тиску в hPa та mmHg.

## Апаратне забезпечення

- Мікроконтролер: STM32F401CCU6
- Сенсор: BME280
- Інтерфейс зв'язку: SPI
- Виведення логів: USB CDC
