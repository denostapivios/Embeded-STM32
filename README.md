# STM32 — Servo Control with Potentiometer
Проєкт для керування сервоприводом SG90 за допомогою потенціометра на STM32.

Що реалізовано:
- Зчитування положення потенціометра через ADC1 у 12-бітному режимі.
- Усереднення 16 ADC-вимірювань для стабілізації показників.
- Перетворення значення ADC у діапазон потенціометра 0–270°.
- Обмеження керування SG90 діапазоном 0–180°.
- Генерація PWM через TIM1 CH1 з частотою 50 Hz.
- Керування SG90 імпульсами 500–2400 μs.
- Оновлення положення сервопривода кожні 20 ms.
- Логіка програми винесена в окремі app.c та app.h.
